# ArkCut 使用指南

ArkCut 用于在本机识别《明日方舟》录屏中的暂停画面，检查剪辑衔接、添加音乐并导出视频。适用平台：Windows 10/11 x64。

## 第一次打开

1. 获取完整便携包，解压到你能正常写入的文件夹。
2. 双击 `ArkCut.exe`。组件齐全时直接进入编辑器；缺少时自动下载并显示准备进度，完成后自动进入。可取消，失败时可重试。
3. 首次准备组件需要联网，完成后可离线使用。无需安装 Node.js、Rust 或 Python。组件保存在当前用户目录，移动程序后仍可复用。

在 GitHub Releases 发布页面选择名称包含 `win64-light` 的 ZIP。源码压缩包供开发者使用，不能直接运行。微软系统安装阶段若取消，会等待安装器结束后退出；已完成的组件保留供下次复用。

若收到名称包含 `win64-offline` 的完整离线包，解压后直接双击 `ArkCut.exe` 即可，无需下载运行组件。请保留包内 `media` 和 `WebView2` 文件夹；程序会校验并使用这些组件。两种包的剪辑功能相同。

## 从录屏到成片

无需选择录屏比例。程序先定位实际游戏画面，再识别暂停文字和战斗控件；画面带黑边或位于方形、竖屏画布中时也会自动定位。请尽量保留完整游戏画面和清晰控件；裁切或遮挡造成证据不足时，可以查看原片并手动调整。

1. **选择录屏**：点击视频区的加号或拖入文件。系统建立帧索引并自动识别暂停画面；较大或高帧率录屏需要更长时间，可查看阶段进度或取消。
2. **检查原片**：识别完成后显示原片。后台准备剪辑预览时，可以继续查看录屏。识别为零段时检查画面是否适配；自动识别结果仍建议逐处确认。
3. **检查剪辑点**：右侧列表显示各处删除时长。单击时间轴黄色区间可高亮对应列表项，并暂停定位到区间起点；双击可直接播放该区间的原片内容，并在区间结尾停止。点击列表播放图标检查剪辑后的衔接，点击“调整”修改起止时间并应用。改动可以撤销、重做。时间轴缩放后可平移查看，区间边界通过调整面板修改。
4. **预览**：点击“生成全部预览”，批量准备所有剪辑点附近的短片段；完成后可逐处切换、重复播放。快速预览会降低清晰度并显示提示，导出仍保持原画质；查看原片和已导出成片时不会显示快速预览提示。预览准备完成不等于整片已经导出。
5. **添加音乐（可选）**：进入“音频”，添加音乐并试听。选中曲目下方可以播放、暂停和查看进度。保留原声即可完成不加音乐的剪辑。
6. **导出**：在“导出”中确认保存位置和文件名，点击“剪辑并导出”。完成后主按钮变成“打开文件夹”；编辑内容变化后，会恢复为“剪辑并导出”。等待导出和检查全部成功后再使用成片。

空格用于播放/暂停；在输入文字或时间时，先完成输入并退出编辑框再控制播放。浅色/深色切换在窗口右上方。“软件设置”提供预览缓存上限和关于信息。

识别暂停画面后，程序会复核暂停附近的短暂选中偏移，减少切换时的一闪或抽动。持续子弹时间、恢复后仍选中的画面以及证据不足的情况保持原样。你手动调整过的边界会保留；复检发现疑似问题时可查看对应位置再决定。旧项目可重新识别，或在预览、导出检查中复核相关自动切点；建议先检查预览再使用成片。

暂停操作密集时，相邻剪辑点可能关联同一段画面。检查结果会合并同一来源帧的重复问题，并保留关联位置；显示的问题数量不等于需要追加删除的区间数量。

## 项目保存与重新打开

关键编辑操作会自动保存，留意顶部保存状态。项目默认位于程序同级“项目存档”；目录不可写时按提示选择可写位置。通过项目菜单的“打开项目”或最近项目继续编辑。最近记录按程序所在目录独立保存，新解压到其他目录时不继承旧副本的记录；没有记录时不显示该栏目。原工程不受影响，可通过“打开项目”继续使用。

工程保存的是编辑信息和素材位置，不会把整份录屏、音乐打包进去。保留原片与音乐的位置，移动项目时一并保留所需素材。程序配置、缓存和日志默认位于 `%LOCALAPPDATA%\ArkCut`。

## 常见问题

| 情况 | 可以怎么做 |
| --- | --- |
| 处理时间较长 | 先看当前阶段和进度；时长、分辨率、帧率及电脑性能都会影响耗时。需要中止时使用取消，之后重新发起任务。 |
| 提示可用内存不足 | 程序先减少并发、分批完成全部预览；真正接近系统内存或提交空间下限时会停止。保存项目，关闭不需要的高占用程序后重试；已完成的有效预览缓存可复用。 |
| 缓存或磁盘空间不足 | 检查输出盘和缓存所在盘的空间；需要更多预览缓存时，在软件设置调整上限。 |
| 预览提示尚未生成或已过期 | 生成或更新预览，等待对应片段就绪后播放。编辑会使相关预览需要更新。 |
| 暂停画面识别不准确 | 查看原片，调整区间；必要时使用项目菜单的人工区间功能。识别未适配的素材需要手动检查。 |
| 成片体积没有明显变小 | 编码与切点处理会影响体积；当前质量优先，无法保证按删掉的时长同比缩小。 |
| 导出检查失败 | 查看问题提示，按界面提供的定位或重试操作处理。确认成功前继续保留原片和已有成片。 |
| 需要报告问题 | 展开底部日志并导出，记录版本、出错步骤和提示。分享前检查日志中的文件名与路径；无需上传私人录屏。 |

当前主要面向 SDR 素材；HDR 及部分特殊旋转/像素格式可能提示不支持。所有媒体处理在本机完成。不同素材的识别效果以及不同硬件的耗时会有差异。

无需选择高配或低配模式。程序按实时可用内存与系统提交空间调整线程数和预览批次；内存偏紧时会降低负载继续识别和处理，接近临界余量才停止。全部片段预览仍会生成，快速预览可降低清晰度，导出保持原画质。

## 更新与版本信息

当前版本为 0.17.1。“软件设置 → 关于 ArkCut”有新版时只显示小红点；手动点击“检查更新”并发现新版本才打开弹窗，同意后下载并保存项目、重启更新。已是最新版本或检查失败时，结果显示在设置页。保存失败时不会退出，更新失败按事务恢复旧版本。发布端点未上线时仍可正常进行本地剪辑，详见[更新与恢复](更新与恢复.md)。

手动更新时先退出程序，将新包解压到新目录；保留旧目录里的“项目存档”、原片和音乐，通过新程序打开工程，确认可用后再处理旧目录。

同一电脑上的多个便携副本分别运行各自的程序。解压新包不会替换已经打开的旧副本；重新打开新目录中的 ArkCut.exe，并在“关于 ArkCut”核对版本。
