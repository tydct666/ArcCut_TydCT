# 更新与恢复

## 检查和安装更新

1. 有新版本时，软件设置入口和“检查更新”按钮显示小红点。后台不会弹窗、显示横幅或自动下载。
2. 点击“软件设置 → 关于 ArkCut → 检查更新”，发现新版本后才打开更新弹窗，显示版本和更新说明。检查进度、已是最新版本或检查失败的提示只显示在设置页。
3. 选择“同意更新”后下载，完成后保存项目并重启安装。选择“暂不更新”或关闭弹窗不安装；下载期间可取消。当前媒体任务未结束时不能确认安装。

程序空闲时会轻量检查版本，检查失败不影响本地剪辑。组件兼容时复用已有版本，需要新组件时先准备再替换程序；失败或取消保留原程序与已验证组件。已经缓存的更新也必须重新手动检查和同意，不会在重启后自动安装。

## 项目会保留吗？

更新会保留项目存档、原片、成片和用户设置。项目依赖原片及音乐的位置，请继续保留这些素材。若保存项目失败，先解决保存问题，再重试更新。

## 更新没有完成

1. 等待界面的恢复提示。程序会尝试恢复旧版本；恢复成功后可继续使用，稍后再重试更新。
2. 如提示文件被占用，关闭同一目录下其他 ArkCut 窗口，确保磁盘有足够空间后重试。
3. 如 ArkCut 无法启动，查看程序目录下的 `.arkcut-update` 文件夹；若其中存在“恢复更新.cmd”，双击后按提示恢复。
4. 仍无法启动时，将完整便携包解压到一个新文件夹，打开新程序，再从旧目录的“项目存档”打开工程。确认项目和素材完整后再整理旧目录。

需要反馈问题时，可导出日志并说明软件版本、操作步骤和界面提示。分享前检查日志中的文件名与路径，保留私人素材。

## 手动更新

退出 ArkCut，将新便携包解压到新文件夹。通过新程序打开已有工程，继续使用原片和音乐。原片、音乐和项目存档单独保留，软件压缩包不会替你备份这些内容。
