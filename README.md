# ArkCut

《明日方舟》录屏去暂停工具，支持 Windows 10/11 64 位。

导入录屏后，ArkCut 会识别暂停区间，把保留的画面接起来。你可以预览剪辑点、调整边界、添加背景音乐，再导出成片。视频和音频都在本机处理。

当前版本：**0.17.5**。

## 功能

- 识别常见 PC、手机录屏中的暂停画面。
- 清理暂停前短暂的选中视角偏移，保留持续选中和无法确定的片段。
- 预览剪辑衔接，手动调整需要保留或删除的区间。
- 添加背景音乐，调整游戏声音与音乐音量。
- 自动保存项目，导出文件名附带时间戳，方便区分多次处理的结果。

## 使用

1. 解压便携包，双击 `ArkCut.exe`。离线包包含运行组件；轻量包首次缺少组件时需要联网下载。
2. 选择或拖入录屏，等待识别完成。
3. 检查剪辑点，按需调整区间和音乐。
4. 点击“剪辑并导出”，完成后打开输出文件夹。

项目默认保存在程序旁的“项目存档”文件夹。工程文件不包含素材，重新编辑时仍需要原片和音乐。

识别不能完全区分短暂选中和有意保留的子弹时间，拿不准的片段会保留。游戏控件被裁掉或遮住时，也可能需要手动调整。导出以画质为先，文件不一定比原片小。

详细操作见[用户指南](docs/用户指南.md)。升级后处理旧项目，可先在项目菜单中重新分析。

## 开发

界面使用 React 和 TypeScript，桌面程序使用 Tauri 和 Rust，媒体处理使用 FFmpeg。

需要 Node.js、pnpm、Rust MSVC 工具链和 Windows C++ Build Tools。

```powershell
pnpm install --frozen-lockfile
./scripts/bootstrap-runtime.ps1
pnpm desktop
```

构建、测试和打包步骤见[构建与发布](docs/构建与发布.md)。

| 目录 | 内容 |
| --- | --- |
| `src` | 界面与交互 |
| `src-tauri` | 识别、时间线和媒体处理 |
| `tests` | 测试与回归检查 |
| `scripts` | 构建、打包和校验脚本 |
| `docs` | 使用与维护文档 |
