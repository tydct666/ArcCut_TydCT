# ArkCut

Windows 10/11 x64 本地录屏剪辑工具：识别《明日方舟》暂停画面，检查剪辑衔接、添加音乐并导出。所有媒体仅在本机处理。

当前版本 **0.17.1**。下载完整便携包，解压后双击 ArkCut.exe。首次缺少组件时自动联网准备，完成后可离线使用；项目默认保存到同级“项目存档”。源码 ZIP 用于开发，不能直接运行。

“软件设置 → 关于 ArkCut”仅以小红点提醒新版；手动检查发现新版本才弹窗，同意后下载并重启更新。其他检查结果显示在设置页。更新使用签名校验与失败恢复；0.16.2 用户需手动解压新包一次。当前尚未推送、发布，真实 GitHub HTTPS 端点验收待完成。真实低配、干净 Windows 首次准备和高 DPI 验收也待补齐。

本机构建后，轻量交付生成在 `dist/ArkCut-0.17.1-win64-light`，可选本地离线包生成在 `dist/ArkCut-0.17.1-win64-offline`；这些生成物不随源码检出提供。公开仓库仅包含经审核的源码；便携包另通过 Releases 发布。新包解压到新目录后，可打开旧目录中的工程继续编辑。

识别结果建议逐处确认，已验证素材不能代表所有录屏。导出质量优先，成片体积可能增加。程序包含资源保护，具体耗时取决于素材和硬件。

确认暂停附近的短暂选中偏移会结合前后画面自动复核；持续选中、暂停后继续的子弹时间和证据不清的画面保持原样。人工调整的边界保留，仍可通过剪辑点预览检查衔接。内存使用按实时余量自动适配，全部片段预览继续分批完成。

识别先定位有效游戏画面和控件，按实际位置与缩放适配，不以视频宽高比作为支持门槛。保留完整游戏内容的黑边、方形或竖屏画布可自动定位；必要控件被裁掉、遮住或过小而无法确认时，会提示检查原片。

0.17.1 修正手机录屏中普通画面被误认作暂停的问题；密集剪辑点的重复残帧与问题合并显示，并保留关联位置。持续子弹时间的保护条件和人工调整边界保持不变。

手机录屏开头先暂停时，剪辑后的方向信息会从原片恢复，避免旋转标记丢失导致导出受阻；媒体像素保持原样。该项完整导出与方向校验仍以本轮实测结果为准。

开发使用 Node 24.19.0、pnpm 11.25.0、Rust MSVC 1.99.1 与 Windows C++ Build Tools。执行 pnpm install --frozen-lockfile、pnpm build；Rust 单元及更新测试、按需运行组件和便携打包步骤见构建文档。

仓库白名单仅包含源码、锁文件、构建脚本、公开文档及必要的第三方分发材料，不包含个人录屏、音乐、工程、缓存、工具链、私钥或历史验收日志。项目许可证见 LICENSE，第三方组件遵循各自许可证；轻量包不附带 FFmpeg 或固定 WebView2，按实际分发内容核验材料；旧离线包的对应源码缺口保留为历史待办。
