# 开始使用 ArkCut

ArkCut 帮你识别《明日方舟》录屏中的暂停画面，检查剪辑衔接、添加音乐并导出视频。所有媒体处理都在本机完成。

1. 将完整压缩包解压到可写入的文件夹。
2. 双击 **ArkCut.exe**，选择或拖入录屏。
   首次缺少组件时会自动下载并准备；完成后进入编辑器。
3. 等待识别完成，逐处检查剪辑点；需要时在“音频”添加音乐。
4. 点击 **剪辑并导出**。成功后点击 **打开文件夹** 查看成片。

支持 Windows 10/11 64 位。首次准备组件需要联网，完成后可离线使用。无需配置开发环境。请保持解压后的目录完整。

- [用户指南](docs/用户指南.md)：播放、调整区间、项目保存和常见问题。
- [更新与恢复](docs/更新与恢复.md)：检查更新、取消下载和更新失败后的恢复方法。
- [第三方运行组件说明](licenses/non-media/README.md)：组件来源、许可与隐私说明。

项目默认保存在程序同级的“项目存档”中。保留原片和音乐，工程文件记录的是编辑内容及素材位置。

软件版本可在“软件设置 → 关于 ArkCut”查看。`licenses`、`sources` 为许可与源码材料，日常使用无需打开。源码材料中的开发文档面向维护者。
