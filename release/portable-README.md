# ArkCut 轻量版

《明日方舟》录屏去暂停工具，支持 Windows 10/11 64 位。

## 开始使用

1. 完整解压压缩包，双击 `ArkCut.exe`。
2. 首次缺少运行组件时，等待程序联网下载并准备。
3. 选择或拖入录屏，检查识别出的剪辑点，按需调整区间和音乐。
4. 点击“剪辑并导出”。成片文件名会带上时间戳。

组件准备完成后可离线使用，视频和音频都在本机处理。

项目默认保存在程序旁的“项目存档”中。工程不包含素材，请保留原片和音乐。

使用方法见[用户指南](docs/用户指南.md)，更新方法见[更新与恢复](docs/更新与恢复.md)。版本号可在“软件设置 → 关于 ArkCut”查看。

请保持解压后的目录完整。`licenses` 和 `sources` 存放第三方许可与源码材料。
