# ArkCut 离线版

《明日方舟》录屏去暂停工具，支持 Windows 10/11 64 位。本包已包含运行组件，无需联网下载。

## 开始使用

1. 完整解压压缩包，双击 `ArkCut.exe`。
2. 选择或拖入录屏，等待识别完成。
3. 检查剪辑点，按需调整区间和背景音乐。
4. 点击“剪辑并导出”。成片文件名会带上时间戳。

视频和音频都在本机处理。项目默认保存在程序旁的“项目存档”中；工程不包含素材，请保留原片和音乐。

使用方法见[用户指南](docs/用户指南.md)。旧项目可通过项目菜单打开，重新分析后使用新版识别结果。

请保留 `media`、`WebView2`、`licenses`、`sources` 和 `docs` 文件夹。版本号可在“软件设置 → 关于 ArkCut”查看。
